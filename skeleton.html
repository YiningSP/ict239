Syllabus overview

  • Week 1–2: Semantic HTML, document structure, accessibility basics.
  • Week 3–4: CSS fundamentals — the cascade, selectors, the box model.
  • Week 5–6: Layout — Flexbox & Grid, responsive design, media queries.
  • Week 7–8: Components — buttons, cards, forms; design tokens and variables.
  • Week 9–10: Interactivity with vanilla JavaScript; DOM manipulation.
  • Week 11: Performance & accessibility checks; DevTools workflow.
  • Week 12: Mini–project showcase & code review.
